二、重点案例详解

1. Volkswagen：工业 AI 要有统一交付流水线和生产监控

  • 来源：AWS：Volkswagen DPP 端到端 MLOps
  • 场景与做法：多工厂质量、维护和预测模型的数据访问、训练、审批与部署方式不一致。DPP 将数据准备、训练、注册、部署和生产监控标准化，并定时检查数据质量、模型质量、偏差和解释性。
  • 技术：SageMaker、Model Monitor、Step Functions、EventBridge、DataZone、API Gateway、S3 与分账户安全护栏。
  • 光伏启发：EL/AOI 模型包必须同时绑定代码、数据版本、阈值、相机/光源、适用品种和审批记录；先单线影子运行，再按设备/班次扩圈。
  • 难度/收益：平台级高、单线只读试点中等。案例称应用建设部署可快 2—3 倍；本厂应独立量化发布工时、回滚时间和误判成本。

2. Siemens Erlangen：云端重训练，模型在产线边缘运行

  • 来源：AWS/Siemens 客户案例
  • 场景与做法：人工配置或重训模型约需 30 分钟。工厂在云端训练/重训练，通过 Siemens Industrial Edge 管理现场部署与运行，形成完整生命周期。
  • 技术：AWS 云训练、Siemens Industrial AI、Industrial Edge、模型生命周期管理。
  • 光伏启发：EL 新模型在服务器训练后封装标准推理包，只在一台检测机双跑；同时考核漏检、误拒、时延和资源占用。
  • 难度/收益：中高。案例方称部署时间缩短 80%、误报率降低 50% 以上、生命周期成本节省 90% 以上，需本厂复测。

3. IC 载板：把操作员复检变成模型迭代数据

  • 来源：ASRock Industrial 案例，2025-06-27
  • 场景与做法：PEGAAi 与边缘 AIoT 设备结合，Auto MLOps 管理优化，以操作员复检形成持续反馈，并用仪表盘跟踪 AI 表现。
  • 技术：边缘 AI、Auto MLOps、工业视觉、复检反馈、性能仪表盘。
  • 光伏启发：EL/AOI 复判界面保存模型版本、原始图、缺陷框、修改原因和处置结果，每日生成高价值误判样本包，但不自动上线。
  • 难度/收益：中等。来源未披露可信量化收益，标记为厂商案例且数字不足。

4. EdgeMLOps：低算力设备也要管理版本和远程状态

  • 来源：EdgeMLOps 论文
  • 场景与做法：用 Cumulocity IoT 与 thin-edge.io 发布视觉质检模型，在 Raspberry Pi 4 比较 FP32、静态 INT8、动态 INT8，并回传检测状态。
  • 技术：thin-edge.io、Cumulocity IoT、模型量化、边缘推理、资产状态同步。
  • 光伏启发：接线盒、铭牌、边框模型发布前必须在目标硬件测时延、内存、温度和丢帧；量化模型保留原模型复核通道。
  • 难度/收益：中等。论文显示 INT8 推理时间优势，但无可直接复用的工厂 ROI，属于研究验证。

5. 摩擦搅拌焊：漂移后，置信度可能比答案更危险

  • 来源：Journal of Intelligent Manufacturing 论文
  • 场景与做法：过程、材料和设备变化令预测概率不再对应真实风险。研究评估漂移条件下的校准方法，示例第二类漂移中纯模型准确率降至 82.2%。
  • 技术：深度学习质量监控、数据漂移、概率校准、可靠性评价。
  • 光伏启发：按版型、玻璃/胶膜、相机和班次切片监控 EL 置信度；切片样本不足只报警，不自动重训。
  • 难度/收益：中高；可提前识别静默失效，但依赖足够的人工复判真值。

6. 半导体材料：固定重训练节奏可能优于反复调参

  • 来源：Robust and Reliable AI for Predictive Quality，2026-05
  • 场景与做法：用五年真实制造数据比较重训练频率；研究发现每五批固定重训练且不重复调参，在多种漂移下表现更优、开销更低，并用保形预测提供置信区间。
  • 技术：批次重训练、残差控制限、保形预测、不确定性量化。
  • 光伏启发：层压后 EL 风险、功率虚拟量测或串焊拉力预测应输出点预测 + 区间；区间跨质量限时转人工/实测。
  • 难度/收益：高；成熟批次数据下中高。可减少无效重训，但每五批结论必须按本厂漂移速度验证。

7. 工业装配线：快模型实时跑，大模型做验证

  • 来源：Procedia CIRP 2025 案例
  • 场景与做法：以活动产线标注图像训练优化 YOLOv8.2s 与验证 YOLOv8.2m，前者执行边缘实时任务、后者负责验证，并与机器人流程集成。
  • 技术：YOLOv8、边缘推理、双模型验证、机器人流程控制。
  • 光伏启发：快速模型全量 EL 初筛，低置信度/严重缺陷进入大模型 + 人工复核；候选模型先作为第三路影子模型。
  • 难度/收益：中高。来源页面未披露可直接引用的量产收益，需要本厂 A/B 回放。

四、结合光伏工厂的应用点子

点子 1：EL/AOI 新旧模型影子双跑与灰度看板

  • 痛点：离线更优不代表所有版型、相机和光源都安全。
  • 思路：同图双跑，候选结果不参与放行；通过门槛后仅一台设备/一个班次灰度。
  • 数据：原图、条码、设备/相机/光源、版型、两路输出、人工复判、返工/复测。
  • 技术：版本化 API + 队列 + 对账表 + 规则门槛 + 一键切回。
  • 复杂度/收益：中等；降低升级导致的批量误放/误拒风险。

点子 2：按版型/材料/设备切片的模型漂移雷达

  • 痛点：总体准确率会掩盖局部恶化。
  • 思路：每日切片监控亮度/纹理、缺陷分布、置信度与人工推翻率；小样本只标黄。
  • 数据：图像特征、BOM/材料、设备、班次、复判和后续检测。
  • 技术：PSI/KS/嵌入距离 + 校准 + 最小样本门槛。
  • 复杂度/收益：中高；更早发现换料或相机维护后的静默失效。

点子 3：模型发布包“六件套”与签名校验

  • 痛点：现场只知模型文件名，无法复现或快速回滚。
  • 思路：绑定模型、代码、标签、阈值、硬件配置和验证报告，签名后由边缘节点拉取。
  • 数据：Git 提交、模型、数据快照 ID、配置、验证指标、审批和设备清单。
  • 技术：OCI Registry + KitOps/制品清单 + 签名 + 审计日志。
  • 复杂度/收益：中等；缩短定位和恢复时间。

点子 4：低置信度样本的复判与主动学习队列

  • 痛点：人工复判散落，新模型重复犯错。
  • 思路：低置信度、新分布、严重缺陷和新材料自动入队；复判须记录原因码与缺陷区域。
  • 数据：图像、预测、置信度、版本、人工框选和最终处置。
  • 技术：任务队列 + Web 复判 + 去重 + 数据版本 + 审批训练。
  • 复杂度/收益：中等；提高复判工时的信息收益和知识沉淀质量。

点子 5：模型升级后的质量后悔值账本

  • 痛点：当日抽样不能说明对返工、复测和客户抽检的真实影响。
  • 思路：每次发布设置 7/14/30 天观察窗，回连返工、复测、库存和客诉，估算继续用旧模型的后悔值。
  • 数据：新旧输出、处置、功率、库存/出货、客诉。
  • 技术：离线双模型回放 + 反事实对账 + 成本权重。
  • 复杂度/收益：中高；让模型 KPI 与质量成本一致。

五、今日最值得尝试的一个小项目

EL 模型“影子双跑 + 一键回滚”只读 MVP

推荐原因：离线测试通过不代表某条产线、某个版型和某台相机都安全。项目不改 PLC、不改变当前放行；先让生产模型与候选模型对同一批图像双跑，用真实复判和后续质量证明是否值得灰度。

MVP：一台 EL 检测机、一个高频版型、最近 2—4 周图像；候选模型仅影子运行。看板展示一致率、新增拦截/误拒、低置信度率、P95 时延、资源和失败率。通过后仅一个班次或 10% 建议态灰度，越界立即切回旧模型。

数据：EL 原图/条码、版型/BOM、设备与相机/光源、两个模型版本与输出、耗时、人工复判、返工/复测/功率和当前放行。

  1. 第 1—2 天：定义严重缺陷、误拒、时延、资源护栏和回滚责任人。
  2. 第 3—4 天：封装两个不可变发布包，绑定权重、代码、阈值、标签和配置。
  3. 第 5—6 天：回放至少 1,000 张，覆盖少数类、换型后和相机维护后样本。
  4. 第 7—8 天：在线影子运行，监控时延、丢帧、资源和漂移，不改写放行。
  5. 第 9 天：按版型、缺陷、设备和班次切片评审，关键切片不达标不灰度。
  6. 第 10 天：仅向指定复判员展示候选建议，演练 5 分钟内切回。

周期与验收：10 个工作日；1,000+ 张有效双跑；版本可追溯率 100%；严重缺陷分歧复核率 100%；P95 时延不超预算；回滚 ≤ 5 分钟；0 次自动改写放行或 PLC。

扩展：同型号设备分批灰度 → 版型/材料/相机漂移雷达 → 7/14/30 天质量后悔值。自动放行需另行完成 MSA、客户规则和异常降级评审。

今日判断：光伏工厂下一步不应只是“再训练一个更准的模型”，而应先建立可证明、可分批、可回退的发布机制。把新旧模型在同一真实数据上双跑，并将分歧交给可追溯的复判，往往比一次大规模替换更快得到可信收益。
